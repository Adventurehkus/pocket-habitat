# AGENTS

This repository defines the following agents for the Pocket Habitat project:

- **explore** – Fast agent for codebase exploration.
- **general** – General‑purpose agent for complex tasks.
- **opencode** – Agent for interacting with the OpenCode platform.
- **report** – Agent for reporting issues.

Each agent lives in its own module under `src/shared/Agents` and follows the OpenCode agent conventions.
