# Pocket Habitat — Development Roadmap

## Milestone 0: Foundation (Current)
- Repository layout and Rojo project configuration (`default.project.json`).
- Rokit version pinning (`rokit.toml`) and dependency setup (`wally.toml`).
- Required documentation suite (`docs/`).
- Initial project structure (`src/server`, `src/shared`, `src/client`, `assets/runtime`).
- Verification of checks and initial project state.

## Milestone 1: Playable Core
- Basic habitat island environment setup.
- Server-authoritative resource collection nodes.
- Planting and growth mechanics (seed to harvest).
- Initial creature discovery and spawn triggers.
- Basic client-server feedback loops.

## Milestone 2: Progression
- Safe, versioned DataStore persistence manager.
- Persistent inventory management system.
- Currency economy (Bells/Shards transactions).
- Quest tracking and reward system.
- Habitat upgrades and zone unlocking.

## Milestone 3: Presentation
- Low-poly environment polishing and atmospheric lighting.
- Dynamic creature animations and behavior states.
- Immersive UI design across all devices.
- Sound effects (SFX) and ambient music integration.

## Milestone 4: Quality Assurance (QA)
- Server-authoritative security hardening & validation.
- Persistence error recovery and robust save migration.
- Multiplayer data isolation and synchronization checks.
- Cross-device input and performance optimization.

## Milestone 5: Release Preparation
- Monetization setup (gamepasses and developer products).
- Final polish, balance pass, and release checklist.
- Readiness review (without publishing credentials).
